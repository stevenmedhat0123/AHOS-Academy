# AHOS Academy — تشغيل المنصة كـ APK

## 1) Firebase (مجاني)
1. console.firebase.google.com ← Add project.
2. Authentication ← Sign-in method ← فعّل **Email/Password** بس.
3. Firestore Database ← Create ← تبويب **Rules** ← الصق محتوى `firestore.rules` ← Publish.
4. Project settings ← Your apps ← Web (</>) ← انسخ `apiKey` و `projectId` وحطهم في **`www/config.js`** (الملف ده بس، والتحديثات الجاية مش هتلمسه).

## 2) المالك
أول حساب يتسجل في التطبيق **هو المالك تلقائياً**، وبيطلب منك باسورد تاني (6+). مع كل فتح للتطبيق لازم الباسورد التاني، وتسجيل الدخول من جهاز جديد لازم الإيميل والباسورد الأول ثم التاني. سجّل حسابك أنت أول واحد قبل ما تشارك التطبيق.
(لو كنت اخترت "اجعلني المالك" قبل كده: ادخل بحسابك وهيطلب منك تعمل الباسورد التاني.)

## 3) أيقونة AHOS (أزرق على أسود)
```
npm install
npx cap add android
npm run icons        # بيولّد الأيقونات من فولدر assets
npx cap sync
npx cap open android # Build ← Build APK(s)
```
بعد أي تعديل في www: `npx cap sync` وابنِ الـ APK تاني.

## الإشعارات
**شغالة مجاناً بدون أي إعداد زيادة:** أي حاجة جديدة (ملف، اختبار، لعبة، فيديو، لايف، إشعار، درجة، رسالة دردشة) بتوصل لكل الطلاب كإشعار على الموبايل مع صوت واهتزاز وعلامة حمرا على القسم، وبتتسجل في قسم الإشعارات. ورسايل اللايف بتوصلك إنت. ده بيشتغل والتطبيق مفتوح أو لسه في الخلفية. من قسم الإشعارات تقدر تقفل الصوت وتجرب إشعار.
اسمح بإذن الإشعارات أول ما التطبيق يطلبه (لو رفضته: إعدادات الموبايل ← التطبيقات ← AHOS ← الإشعارات).

**علشان توصل والتطبيق مقفول تماماً (اختياري):** محتاج خطة Blaze في Firebase (فيها حصة مجانية بس بتطلب كارت) :
1. Project settings ← Add app ← Android، اكتب Package name: `com.ahos.academy`، ونزّل `google-services.json` وحطه في `android/app/` (بعد `npx cap add android`).
2. نفّذ في فولدر المشروع: `npm i -g firebase-tools` ثم `firebase login` ثم `firebase use --add` (اختار مشروعك).
3. `cd functions && npm install && cd ..` ثم `firebase deploy --only functions`.
4. `npx cap sync` وابنِ الـ APK تاني.

## رفع الفيديو والملفات (مجاني، من غير كارت)
الرفع بيتم على Cloudinary، والطالب يشوف الفيديو ويقرأ الـ PDF جوه التطبيق (الـ PDF بيتعرض صفحات صور، والفيديو بمشغل داخلي من غير زرار تحميل).
1. اعمل حساب مجاني على cloudinary.com، وانسخ **Cloud name** من الـ Dashboard.
2. Settings ← Upload ← Add upload preset ← **Signing mode: Unsigned** ← (حدد Folder: `ahos`، وفي Allowed formats وحد الحجم لو متاح) ← Save، وانسخ اسم الـ preset.
3. حطهم في `www/uploads-config.js` (cloud و preset). **ما تنسخش config.js الجديد فوق القديم**.
4. `npx cap sync` وابنِ الـ APK. هيظهر لك زرار "📎 رفع من الموبايل" في الملفات والفيديوهات والاختبارات والألعاب واللايف، وبعد الرفع اضغط إضافة.
ملاحظات: لو صفحات الـ PDF ما ظهرتش: Settings ← Security ← فعّل PDF delivery. حدود حجم الملف في الخطة المجانية بتتغير (تقريباً 10 ميجا للـ PDF والصور و100 ميجا للفيديو)، راجعها في حسابك. روابط Cloudinary غير معلنة بس مش محمية بالكامل، فالطالب اللي ينسخ الرابط يقدر يشاركه؛ الحماية الكاملة محتاجة Firebase Storage (خطة Blaze). ولو يوتيوب طلّع خطأ 153 داخل التطبيق استخدم الرفع بدل رابط يوتيوب.

## الاختبارات والتقارير
- **إنشاء اختبار** (إنت): قسم الاختبارات ← ➕ اختبار جديد. اكتب العنوان والمدة والأسئلة كده: سطر للسؤال وتحته الاختيارات كل واحد في سطر بشرطة، وحط `*` بعد الإجابة الصح، وسطر فاضي بين كل سؤالين.
- الطالب بيحل بعداد تنازلي، والتصحيح تلقائي، وبيشوف الإجابات الصح بعد التسليم، والنتيجة بتدخل في متوسطه، وما يقدرش يعيد الاختبار.
- **النتايج والتقارير** (إنت): 📊 جوه قسم الاختبارات: متوسط كل طالب، وزرار 💬 يبعت تقرير لولي الأمر على واتساب، وقايمة اللي اشتراكهم هيخلص خلال 3 أيام، وزرار تصدير CSV بكل بيانات الطلاب (بيفتح في Excel).
- الطالب بيجيله إشعار قبل انتهاء اشتراكه بـ 3 أيام.
- ملاحظة أمان: التصحيح بيتم جوه التطبيق، فطالب متمكن تقنياً ممكن يطلع على الإجابات. للاختبارات اللي بتحسم درجات مهمة محتاج تصحيح على السيرفر (Cloud Function).
- الصق `firestore.rules` الجديد في Firebase واضغط Publish.

## الدردشة الخاصة المشفرة
من قسم الدردشة ← 🔒 محادثات خاصة. أول مرة بتختار يوزر، وبعدها تدور على أي حد بيوزره أو رقم موبايله وتبدأ محادثة.
- التشفير من طرف لطرف: الرسايل والملفات والصوت بتتشفر على الموبايل قبل الرفع، ومفتاح الفك مع الطرفين بس. حتى إنت كمالك ما تقدرش تقراها.
- الرسايل: نجمتين (وصول واستلام) زرق، وبيتحولوا أسود لما الرسالة تتشاف. اضغط على الرسالة: تعديل، حذف عندي، حذف عند الطرفين. زرار "إيصال القراءة" لو قفلته مش هتشوف إن حد شاف رسالتك وهو كمان ما يشوفش إنك شفت.
- الصور والفيديو والصوت والملفات بترفع (مشفرة) على Cloudinary وبتحتاج إعداد الرفع اللي فات، والحد حوالي 9 ميجا للملف. للفيديوهات الأكبر استخدم قسم الفيديوهات.
- **للتسجيل الصوتي** افتح `android/app/src/main/AndroidManifest.xml` بعد `npx cap add android` وضيف قبل `<application`:
  `<uses-permission android:name="android.permission.RECORD_AUDIO" />` و `<uses-permission android:name="android.permission.MODIFY_AUDIO_SETTINGS" />`
- حدود مهمة: رقم الموبايل في الدليل مش متحقق منه (محتاج SMS)؛ لو دخلت من موبايل جديد بيتعمل مفتاح جديد والرسايل القديمة بتظهر "رسالة قديمة"؛ والرسايل بتتخزن على الجهاز نفسه مفكوكة.
- الصق `firestore.rules` الجديد وPublish.

## لوحة الشرف والحضور وجهاز واحد وPDF على السبورة
- **🏆 لوحة الشرف:** إنت بتضغط "نشر / تحديث اللوحة" في صفحتها، فبتحسب أعلى 10 طلاب بمتوسط الاختبارات وتظهر لكل الطلاب.
- **✋ الحضور بكود:** إنت تختار المدة وتضغط "ابدأ الحصة" فيطلع كود من 4 أرقام، والطالب يكتبه ويتسجل حضوره مرة واحدة بس طول المدة. بتشوف أسماء الحاضرين وقت تسجيلهم.
- **📱 جهاز واحد لكل حساب:** أول جهاز يدخل منه الطالب بيتربط بحسابه، وأي جهاز تاني بيظهر له رسالة منع. لو غيّر موبايله أو مسح بيانات التطبيق، اضغط "📱 فك ربط الجهاز" جنب اسمه في لوحة المالك. ده منع على مستوى التطبيق، مش حماية مطلقة على السيرفر.
- **السبورة + PDF:** زرار 📄 PDF (ليك إنت بس، ومحتاج إعداد الرفع) بيرفع الملف وبيعرض صفحاته خلف الرسم، مع تنقل بين الصفحات وحفظ الرسم فوق الصفحة. الصق `firestore.rules` الجديد وPublish.
