# AHOS Academy — تحديث نسخة الويب

الرابط: https://stevenmedhat0123.github.io/AHOS-Academy/  (لو رابطك مختلف خده من Settings ← Pages)

## كل تحديث
1. فك ضغط الـ ZIP (Files ← Extract).
2. المستودع ← Add file ← Upload files ← **كل الملفات** ← Commit changes. (ما تلمسش config.js ولا uploads-config.js.)
3. استنى دقيقتين، وافتح **status.html** في Chrome (نفس الرابط + status.html). هتشوف رقم النسخة وقايمة ✅/❌.
   - ✅ كله والرقم صح: التطبيق هيتحدث لوحده (بيعمل Reload وحده لما يلاقي ملفات جديدة، لما تفتحه أو ترجعله، وكل 10 دقايق).
   - لو لسه قديم: اضغط **مسح الكاش وإعادة التحميل** في status.html (ما بيطلعكش من حسابك).
   - ❌ على ملف: ارفعه تاني. صفحة 404: الملفات اترفعت في مكان غلط أو Pages لسه ما نشرتش (Actions ← "pages build and deployment").
4. في التطبيق: المزيد ← آخر السطر بيكتب `AHOS · build ...` وده رقم النسخة اللي شغالة.

## Firebase
الصق `firestore.rules` في Firebase ← Rules ← Publish (مرة بعد كل ZIP فيه تغيير فيها).

## رفع فيديو بأي حجم من الموبايل (بدون لينك)
- ملف لحد 10 ميجا (صور، PDF، فيديو قصير، صوت): بيترفع على Firebase عادي، من غير أي إعداد زيادة.
- **فيديو أو صوت أكبر من 10 ميجا:** بيترفع على **Firebase Storage** وبيتشغل للطالب مباشرة (من غير ما ينزّله كله). ده محتاج تفعّله مرة واحدة:
  1. Firebase ← Build ← **Storage** ← Get started.
  2. هيطلب ترقية لخطة **Blaze** (محتاجة كارت بنكي؛ ليها حصة مجانية وبتدفع بس لو عديتها). وافق، اختار مكان (الأفضل نفس مكان Firestore) واضغط Done.
  3. تبويب **Rules** ← امسح اللي مكتوب والصق محتوى ملف `storage.rules` ← **Publish**.
  4. (مهم) Billing ← Budgets & alerts ← اعمل تنبيه بمبلغ صغير علشان تعرف لو الاستهلاك زاد.
- لو مفعّلتش Storage، رفع ملف أكبر من 10 ميجا هيطلع رسالة بتقولك كده. الفيديوهات والصور والملفات بتحتاج نت وقت التشغيل.
- **اللينك بقى اختياري:** زرار 🔗 صغير بيظهر خانة اللينك لو احتجتها، وبعيد عن كده الرفع من الموبايل هو الأساس.
